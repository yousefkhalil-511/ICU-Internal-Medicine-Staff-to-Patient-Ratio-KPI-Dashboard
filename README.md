# ICU-Internal-Medicine-Staff-to-Patient-Ratio-KPI-Dashboard
Power BI dashboard analyzing nursing staff-to-patient ratios in the ICU and Internal Medicine ward (Jan–Apr 2026). It tracks target ratio, HPPD, RN mandate compliance, skill mix, acuity, occupancy and labor cost across 600 unit-shifts, with a drill-through page for shift-level root-cause analysis of understaffing.
